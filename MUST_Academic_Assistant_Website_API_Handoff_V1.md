### **Do not duplicate backend logic** 

Do NOT code GPA limits, prerequisites, semester rules, course logic, prompts, RAG calls, or LLM calls inside the website backend. The website integration is transport + UI. The Academic Assistant backend remains the single source of runtime advising behavior. 

## **2. session_id - Required Conversation Identifier** 

session_id is generated by the website/frontend (or the website backend) when a new chat starts. It is not a student ID and should never be typed by the student. 

- Generate one session_id for one conversation. 

- Reuse the exact same session_id for every message in that conversation. 

- Generate a new session_id for a new chat. 

- Minimum API length: 8 characters. 

- Recommended generator in browser/server JavaScript: crypto.randomUUID(). 

- Do not create a new session_id for each message. 

// Example const sessionId = crypto.randomUUID();

## **5. Mandatory Onboarding Behavior** 

The backend requires these three profile values for the current text flow: 

- GPA 

- Completed credit hours 

- Major: AI / CS / IS / General 

User: Hello 

API returns answer asking for: - GPA - completed credit hours - major 

User: My GPA is 2.8 and I have completed 70 credit hours 

API stores: gpa = 2.8 completed_hours = 70 major = null 

API asks only for major. User: My major is AI 

API stores major = AI onboarding_complete = true 

### **Website behavior** 

The website does NOT need a separate hard-coded onboarding form unless the UI team wants one. The safest integration is to display response.answer exactly; the backend asks for only the missing fields. If the UI uses response.profile/onboarding_complete, that is optional presentation state, not academic logic.

## **12. Image / Academic Record Endpoint - NOT Required for Current Website Text Handoff** 

A file-upload foundation already exists, but automatic image/PDF extraction is not part of the current text handoff. 

POST /session/{session_id}/transcript multipart/form-data: file = JPG | PNG | PDF maximum size = 10 MB Current state: status = "uploaded" extraction_status = "pending" 

### **Do not build website logic around this yet** 

The next enhancement will broaden this into Academic Record image/PDF processing so the agent can extract GPA, completed hours, major, and completed courses when visible. Until extraction is enabled and re-documented, the website text integration should ignore this endpoint.
